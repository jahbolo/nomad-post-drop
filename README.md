# nomad-post-drop

Rendered Nomad Energy post images, staged here so they can be posted to the Nomad Energy Facebook Page by URL (raw.githubusercontent.com).

- `posts/<date>-<slug>/` holds the PNG slides of one post, numbered in order.
- `scripts/render.py` renders every canvas of a Nomad post HTML file to PNGs at exact size.
- `log.md` lists what was posted.
